# DocAssist: AI-Powered Documentation Assistant

DocAssist is a Retrieval-Augmented Generation (RAG) based AI assistant designed to provide accurate, context-aware, and source-backed responses from technical documentation.

## Project Overview

The system combines semantic search with Large Language Models (LLMs) to reduce hallucinations and improve the reliability of AI-generated responses. It processes technical documentation through scraping, chunking, embedding generation, and vector indexing to create a searchable knowledge base.

## Features

* Retrieval-Augmented Generation (RAG)
* Semantic document search
* Source-backed responses
* Real-time chat interface
* Documentation scraping and indexing
* MongoDB Atlas vector search

## Tech Stack

* Frontend: Next.js
* Backend: Node.js, Express.js
* AI Pipeline: Python
* Database: MongoDB Atlas
* Vector Search: MongoDB Vector Search
